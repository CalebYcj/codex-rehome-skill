# Security

Do not publish a personal Codex migration package. It can contain conversation history, project files, local paths, generated artifacts, and other private material.

The standard workflow excludes authentication data, cookies, `.env` files, private keys, `.git`, `node_modules`, virtual environments, and runtime files. If you find a bypass or an unintended inclusion path, report it privately to the repository owner instead of opening a public issue with a package attached.
